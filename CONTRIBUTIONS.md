# Bear Blog Contributions

Bear Blog is currently **not accepting contributions**. Bear is not a community built project but instead a source-available platform.  

The primary purpose of making the source code available is to allow others to use the code for personal, non-commercial projects or to satisfy their curiosity about how Bear works. 

If you would like to support the project, consider upgrading your blog. This unlocks neat features and helps fund ongoing development, and keeps [Herman](https://herman.bearblog.dev) caffeinated.
