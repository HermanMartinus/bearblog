# Bear Blog Contributions

Bear Blog is currently **not actively accepting contributions**. Bear is not a community built project but instead a source-available platform.  

The primary purpose of making the Bear Blog source code available is to allow others to use the code for personal, non-commercial projects or to satisfy their curiosity about how Bear works. 

If you would like to support Bear Blog, consider upgrading your blog. Upgrading provides additional features and helps fund ongoing development and maintenance, and keeps [Herman](https://herman.bearblog.dev) caffeinated.
